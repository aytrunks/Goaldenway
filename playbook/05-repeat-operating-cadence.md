# Step 5: Repeat

> Most people spend time on low-ROI activities that aren't correlated with revenue. The second you have any money
> coming in, you can use that to bootstrap everything else.

## Revenue-correlated vs. not

| ✅ Do (correlated with revenue) | ❌ Skip (feels productive, isn't) |
| --- | --- |
| Sending cold emails and proposals | Logo, brand, and website polish |
| Recording demo Looms | Taking a 4th course |
| Sales calls | Learning a new tool "just in case" |
| Delivering and reporting results | Perfecting a template nobody has bought |
| Pitching retainers and upsells | Posting content with no call to action |
| Asking for referrals | Business cards, LLC paperwork past the minimum |

## Weekly operating cadence

| Day | Focus |
| --- | --- |
| Monday | Review the dashboard scorecard: last week's numbers against targets. Set this week's outbound volume. |
| Tuesday–Thursday | Mornings: sales calls and delivery. Afternoons: proposals, Looms, follow-ups. |
| Friday | Client reports and retainer check-ins. Fix one bottleneck in your own systems. |
| Daily (30 min) | Community routine. Answer positive replies within 1 hour. |

## Weekly scorecard (tracked in the dashboard)

| Metric | Target |
| --- | --- |
| Cold emails sent | 1,000+ |
| Upwork proposals | 25+ |
| Positive replies | 10+ |
| Calls held | 3–5 |
| Deals closed | 1+ |
| Retainer pitches made | Every client past day 21 |
| MRR | Up and to the right |

## Reinvestment order

Put the first dollars in, in this order. Each item should pay for itself before you add the next.

1. **$0–1K MRR:** Email infrastructure (domains, inboxes, Instantly). About $200/month.
2. **$1–3K MRR:** Apify and Apollo credits for better lists.
3. **$3–5K MRR:** A **part-time virtual assistant** (about $800–1,500/month).
4. **$5–10K MRR:** More inboxes and domains to double outbound volume.
5. **$10K+ MRR:** A full-time VA. Consider a junior builder for delivering the Starter tier.

## Virtual assistant SOP

One VA can run everything except sales calls and complex builds.

| Area | VA tasks | Frequency |
| --- | --- | --- |
| Lead gen | Run Template 4 for your own ICP, QA the lists, load campaigns | Weekly |
| Inbox | Sort replies, send the booking link to positive replies, flag hot ones | Daily |
| Upwork | Monitor saved searches, draft proposals from the formula for your approval | Twice daily |
| Onboarding | Run Template 3 for new clients, gather access and credentials | Per client |
| Reporting | Compile the monthly client reports and update the dashboard | Monthly / weekly |
| Community | Schedule LinkedIn posts from your build screenshots | Weekly |

Record a Loom for each task the first time you do it yourself, and hand over that Loom as the SOP.

## The loop

```
Learn (once) → Templates (once, refine forever) → Leads (daily) → Deliver → Retain & ascend
      ↑                                                                          │
      └──────────── reinvest profit into lead volume + VA leverage ──────────────┘
```
