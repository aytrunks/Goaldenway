# Content Calendar — superseded

This doc assumed one format posted per calendar day, rotating A → B → C. That's not how the work
actually happens: each boat gets all 3 formats (long-form, short-form, carousel) from the same
edit session, using one hook across all three. There's no day-by-day schedule to follow.

**Use the [campaign hub](https://claude.ai/code/artifact/31d47080-873c-4742-90af-e4295aeb0c8e)
instead** — it hands you the current hook and all 3 ready-to-copy captions, and moves to the next
hook automatically each time you tap "+1 done."

Kept here for history; the day-based table originally in this file no longer reflects the real
workflow.
