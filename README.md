# Goaldenway

Instagram marketing system for the Boat House (Cape Coral, FL).

Brand: **Goaldenway** — your goal + the golden moment + the way to get there. Golden-hour light,
before/after transformation, Ryan Reynolds–style self-aware tone.

## The whole system is one link

**[Open the campaign hub](https://claude.ai/code/artifact/31d47080-873c-4742-90af-e4295aeb0c8e)**

The real workflow: one boat gets edited into 3 posts (long-form, short-form, carousel), all using
the same hook. The hub hands you the current hook, generates all 3 captions ready to copy, and
tracks exactly two numbers — boats posted, DMs received — as tap counters. No calendar, no daily
log, no checklist. When a boat's done, tap "+1 done" and it moves to the next hook automatically.
When a DM comes in, tap "+1 DM" and reply fast — that's the only thing that matters early on.

There's a "Copy a quick update for your boss" button that generates the whole pitch: *"Posted
content from N boats, M DMs in."* That's the proof-of-concept, not a spreadsheet review.

## Everything else in this repo is optional, kept for reference

- `campaign/Goaldenway_Boathouse_Tracker.xlsx` — a full formula-driven tracker (Hook Bank rollups,
  format comparison, auto-written boss pitch) from an earlier, heavier version of this system.
  Untouched, still works, worth opening later if volume ever justifies a real per-hook/per-format
  breakdown. Not part of the daily workflow.
- `campaign/CAPTIONS.md` — the hook-writing reference: all 13 Reynolds-style hooks with the ad
  technique behind each one (researched from real Mint Mobile / Aviation Gin campaigns).
- `campaign/CONTENT_CALENDAR.md`, `campaign/POSTING_CHECKLIST.md` — superseded by the hub, kept
  for history.
- `campaign/BOSS_PITCH_TEMPLATE.md` — the pitch reminder, updated to match the hub's simple proof.

## Why it got this simple

Two rebuilds back this was a 30-day calendar with a daily log, a posting checklist, and a
5-sheet tracker. That assumed one format posted per day on a fixed schedule. It didn't match how
the work actually happens (one boat → three posts, whenever a boat's done) and it asked for more
daily upkeep than was worth it before there's real DM volume to analyze. The hub is what's left
after cutting everything that wasn't earning its keep.
